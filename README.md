# ASTROWORLD: TRAVIS SCOTT EXPERIENCE (Fabric 1.20.1)

Фан-мод: пульт вызывает гигантского исполнителя (40 блоков) и запускает концерт из 5 фаз.
Стилизованная кубическая модель, не фотопортрет. **Музыка в мод не включена** — вы кладёте свои файлы сами.

## Сборка (нужен интернет, JDK 17 и Gradle 8.5+)
    gradle wrapper --gradle-version 8.8     # один раз
    ./gradlew build                          # jar: build/libs/astroworld-1.0.0.jar
Без локальной установки: залейте папку в GitHub — workflow `.github/workflows/build.yml` соберёт jar.
Для разработки: `./gradlew runClient`. (Текстуры пересоздаются: `python3 tools/generate_assets.py`.)

## Установка
Fabric Loader 0.15+, **Fabric API 0.92.2+1.20.1**, Minecraft 1.20.1. Положите jar в `mods/`.

## Игра
* Крафт: `[ ][Незер-звезда][ ] / [Редстоун-блок][Алмаз][Редстоун-блок] / [ ][Золотой слиток][ ]`, или `/astroworld give` (OP).
* ПКМ — старт. Повторный ПКМ ничего не запускает повторно. **Shift+ПКМ — завершить** концерт. `/astroworld start|stop` (OP).
* Сцена появляется в 90 блоках перед вами по взгляду. Всё рисуется на клиенте — блоки мира не ломаются, мир сам «возвращается» за ~10 с после конца.

## Фазы (длительность в config/astroworld.json)
1. PRE_SHOW — небо темнеет, молнии, дрожь земли, дым из-под земли, красный луч и силуэт.
2. ARRIVAL — растут сцена и экраны, вспышка, столб света, ударная волна, гигант проявляется.
3. THE_SHOW — танец в ритм BPM, лазеры, LED-экраны, огненные столбы, волны по земле.
4. ASTROWORLD_CHAOS — максимум: прыжки, хедбэнг, стробо, фейерверки, огонь.
5. FINALE — фейерверки, вспышки, поклон и исчезновение.

## Музыка
Папка `<игра>/astroworld_music/` (создаётся при первом запуске): `preshow.ogg`, `arrival.ogg`, `show.ogg` (или show1.ogg, show2.ogg…), `chaos.ogg`, `finale.ogg`. Трек меняется на смене фазы. **Только OGG Vorbis**; MP3 сначала конвертируйте: `ffmpeg -i song.mp3 -c:a libvorbis song.ogg`.
Громкость: PageUp/PageDown, `/astrovol 0-100` или `musicVolume` в конфиге. Ритм эффектов задаёт `bpm` в конфиге — выставьте BPM вашего трека.

## Конфиг (`config/astroworld.json`)
`giantHeightBlocks` (30–50), `bpm`, длительности фаз, `stageDistance`, `effectRadius`, `musicVolume`, `cameraShake`, `skyEffects`, `lasers`, `flashes` (false = без вспышек, для светочувствительных).

## Статус проверки
Код написан под Yarn 1.20.1+build.10 / Fabric API 0.92.2, но **не компилировался** (в среде автора нет доступа к Maven Fabric). Возможны мелкие правки при первой сборке — присылайте лог.
